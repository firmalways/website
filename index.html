AI ได้คำถามของคุณ แต่ไม่ได้ข้อมูลลูกค้าของคุณ

FirmAlways Gate ซ่อนเลขบัตรประชาชน ชื่อ เบอร์โทร เลขบัญชี และข้อมูลอ่อนไหวตาม PDPA ก่อนข้อความออกจากองค์กร แล้วใส่ค่าจริงคืนในคำตอบให้คุณ ฟรีและเปิดโค้ดให้ตรวจสอบทุกบรรทัด

สิ่งที่ AI ได้รับ

ตัวอย่างนี้ทำงานในเบราว์เซอร์ของคุณเท่านั้น ไม่ส่งข้อความไปที่ใด และใช้กฎเพียงบางส่วนของ Gate ตัวจริง

ติดตั้ง Gate ดูโค้ดบน GitHub

ทำงานอย่างไร

Gate ตั้งอยู่ระหว่างแอปของคุณกับผู้ให้บริการ AI ใช้ได้กับทุกเครื่องมือที่ต่อ OpenAI API ได้ แค่เปลี่ยน base_url

  1. ตรวจ

    หาข้อมูลส่วนบุคคลภาษาไทยในข้อความและไฟล์แนบ ด้วยกฎที่รู้จักรูปแบบไทย เช่น checksum ของเลขบัตร และชื่อที่เขียนติดกันโดยไม่เว้นวรรค

  2. ซ่อน หรือ บล็อก

    แทนค่าจริงด้วย «PERSON_1» ก่อนส่งออก และไม่ส่งเลยถ้าพบรหัสผ่าน API key หรือข้อมูลอ่อนไหวตามมาตรา 26

  3. คืนค่า

    เมื่อ AI ตอบกลับ Gate ใส่ค่าจริงคืนในเครื่องของคุณ และซ่อนข้อมูลใหม่ที่ AI อาจตอบออกมาเอง

ข้อมูลอ่อนไหวตาม PDPA มาตรา 26

สุขภาพ ศาสนา ประวัติอาชญากรรม ความพิการ ข้อมูลชีวภาพ พันธุกรรม ความคิดเห็นทางการเมือง สหภาพแรงงาน พฤติกรรมทางเพศ และเชื้อชาติ Gate บล็อกเมื่อข้อมูลเหล่านี้อยู่คู่กับตัวบุคคล ส่วนคำถามทั่วไปอย่าง "อาการเบาหวานมีอะไรบ้าง" ยังถามได้ตามปกติ

ติดตั้ง

ต้องมี Python 3.11 ขึ้นไป หรือ Docker

สคริปต์ติดตั้ง

curl -fsSL https://firmalways.meapplication.co.th/install.sh | sh

สคริปต์ติดตั้งเวอร์ชันล่าสุดด้วย uv, pipx หรือ pip อ่านสคริปต์ก่อนรัน

หรือดาวน์โหลดสคริปต์เดียวกันจาก GitHub release

curl -fsSL https://github.com/firmalways/gate/releases/latest/download/install.sh | sh

Docker

docker run --rm -p 8787:8787 -e FIRMALWAYS_GATE_API_KEY=change-me \
  -v "$PWD/policy.toml:/etc/firmalways/policy.toml:ro" ghcr.io/firmalways/gate

ลองดูว่า AI จะได้รับอะไร

firmalways-gate scan "ลูกค้าคุณสมชาย ใจดี เลขบัตร 1101700203611"

ใช้กับแอปที่มีอยู่

from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:8787/v1", api_key="<FIRMALWAYS_GATE_API_KEY>")

ใช้ได้กับ OpenAI, Azure OpenAI ในบัญชีของคุณเอง, endpoint ที่รองรับ OpenAI API และโมเดลในเครื่อง เช่น Ollama ดูวิธีตั้งค่าทั้งหมดได้ใน README และส่วนขยายเบราว์เซอร์สำหรับ ChatGPT, Claude และ Gemini ใน extension

สิ่งที่ Gate สัญญา

  • ติดตั้งในเครื่องหรือ cloud ของคุณ Gate ไม่ติดต่อเซิร์ฟเวอร์ของเราเลย
  • ถ้าตรวจข้อความไม่สำเร็จ จะไม่ส่งต่อ ไม่มีการปล่อยข้อมูลออกไปแบบไม่ได้ตรวจ
  • บันทึก audit เฉพาะจำนวนและประเภทข้อมูล ไม่บันทึกข้อความ คำตอบ หรือค่าจริง
  • ค่าที่ถูกซ่อนเก็บอยู่ในหน่วยความจำของคำขอนั้นเท่านั้น แล้วหายไป
  • key ของผู้ให้บริการ AI อยู่ที่ Gate แอปของพนักงานไม่ต้องรู้

คำถามที่พบบ่อย

ใช้แล้วองค์กรผ่าน PDPA เลยไหม

ไม่ Gate ช่วยลดความเสี่ยงและช่วยงานด้าน PDPA แต่การปฏิบัติตามกฎหมายยังต้องมีนโยบาย ความยินยอม สัญญากับผู้ประมวลผล และบันทึก ROPA

ตรวจจับได้ครบ 100% ไหม

ไม่มีเครื่องมือไหนทำได้ เราเปิดเผยผลทดสอบและข้อจำกัดไว้ใน GitHub และถ้าพบช่องโหว่ แจ้งได้ตาม SECURITY.md

ซ่อนชื่อแล้ว AI ยังรู้อะไรได้บ้าง
