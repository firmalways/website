ซ่อนข้อมูลส่วนบุคคลก่อนส่งให้ AI ด้วย FirmAlways Gate

AI ได้คำถามของคุณ แต่ไม่ได้ข้อมูลลูกค้าของคุณ Gate ซ่อนเลขบัตรประชาชน ชื่อ เบอร์โทร เลขบัญชี และข้อมูลอ่อนไหวตาม PDPA ก่อนข้อความออกจากองค์กร แล้วใส่ค่าจริงคืนในคำตอบให้คุณ ฟรีและเปิดโค้ดให้ตรวจสอบทุกบรรทัด

ติดตั้ง Gate ดูโค้ดบน GitHub

ลองดูว่า AI จะได้รับอะไร

สิ่งที่ AI ได้รับ

ตัวอย่างนี้ทำงานในเบราว์เซอร์ของคุณเท่านั้น ไม่ส่งข้อความไปที่ใด และใช้กฎเพียงบางส่วนของ Gate ตัวจริง

FirmAlways Gate ทำงานอย่างไร

Gate ตั้งอยู่ระหว่างแอปของคุณกับผู้ให้บริการ AI ใช้ได้กับทุกเครื่องมือที่ต่อ OpenAI API ได้ แค่เปลี่ยน base_url

  1. ตรวจข้อความและไฟล์

    หาข้อมูลส่วนบุคคลภาษาไทย ด้วยกฎที่รู้จักรูปแบบไทย เช่น checksum ของเลขบัตร และชื่อที่เขียนติดกันโดยไม่เว้นวรรค

  2. ซ่อนหรือบล็อก

    แทนค่าจริงด้วย «PERSON_1» ก่อนส่งออก และไม่ส่งเลยถ้าพบรหัสผ่าน API key หรือข้อมูลอ่อนไหวตามมาตรา 26

  3. คืนค่าในคำตอบ

    เมื่อ AI ตอบกลับ Gate ใส่ค่าจริงคืนในเครื่องของคุณ และซ่อนข้อมูลใหม่ที่ AI อาจตอบออกมาเอง

ติดตั้ง FirmAlways Gate

ต้องมี Python 3.11 ขึ้นไป หรือ Docker

สคริปต์ติดตั้ง

curl -fsSL https://firmalways.meapplication.co.th/install.sh | sh

สคริปต์ติดตั้งเวอร์ชันล่าสุดด้วย uv, pipx หรือ pip อ่านสคริปต์ก่อนรัน หรือใช้สคริปต์เดียวกันจาก GitHub release

curl -fsSL https://github.com/firmalways/gate/releases/latest/download/install.sh | sh

Docker

docker run --rm -p 8787:8787 -e FIRMALWAYS_GATE_API_KEY=change-me \
  -v "$PWD/policy.toml:/etc/firmalways/policy.toml:ro" ghcr.io/firmalways/gate

ลองดูว่า AI จะได้รับอะไร

firmalways-gate scan "ลูกค้าคุณสมชาย ใจดี เลขบัตร 1101700203611"

ใช้กับแอปที่มีอยู่

from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:8787/v1", api_key="<FIRMALWAYS_GATE_API_KEY>")

ใช้ได้กับ OpenAI, Azure OpenAI ในบัญชีของคุณเอง, endpoint ที่รองรับ OpenAI API และโมเดลในเครื่อง เช่น Ollama ดูวิธีตั้งค่าทั้งหมดใน README และส่วนขยายเบราว์เซอร์สำหรับ ChatGPT, Claude และ Gemini ใน extension

สิ่งที่ FirmAlways Gate สัญญา

  • ติดตั้งในเครื่องหรือ cloud ของคุณ Gate ไม่ติดต่อเซิร์ฟเวอร์ของเราเลย
  • ถ้าตรวจข้อความไม่สำเร็จ จะไม่ส่งต่อ ไม่มีการปล่อยข้อมูลออกไปแบบไม่ได้ตรวจ
  • บันทึก audit เฉพาะจำนวนและประเภทข้อมูล ไม่บันทึกข้อความ คำตอบ หรือค่าจริง
  • ค่าที่ถูกซ่อนเก็บอยู่ในหน่วยความจำของคำขอนั้นเท่านั้น แล้วหายไป
  • key ของผู้ให้บริการ AI อยู่ที่ Gate แอปของพนักงานไม่ต้องรู้
