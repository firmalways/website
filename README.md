# firmalways.meapplication.co.th

Static website for FirmAlways Gate (`/`) and FirmAlways Pro (`/pro/`). Plain HTML and CSS, no build step, fonts self-hosted so visitors make no third-party requests. Published with GitHub Pages from `main`.

- `install.sh` is a copy of `firmalways/gate/install.sh`; update both together.
- Preview locally: `python3 -m http.server -d . 8000`
