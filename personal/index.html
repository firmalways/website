FirmAlways Personal ใช้ AI ได้เหมือนเดิม โดยข้อมูลส่วนตัวไม่หลุดออกไป

Hook ที่ติดตั้งครั้งเดียวแบบ RTK แล้วตรวจทุกข้อความก่อนส่งให้ AI ใน ChatGPT Desktop, Codex และ Claude Code ถ้าพบชื่อ เบอร์โทร เลขบัตรประชาชน หรือรหัสผ่าน ข้อความนั้นจะไม่ถูกส่ง และฉบับที่ซ่อนข้อมูลแล้วจะอยู่ในคลิปบอร์ดให้กดวางแล้วส่งต่อได้ทันที

ก่อน AI เปิด PDF, Word, Excel, CSV หรือรูปภาพ FirmAlways อ่านไฟล์นั้นในเครื่องก่อน รวมถึงหน้าสแกนด้วย OCR ภาษาไทย ถ้าพบข้อมูลส่วนตัว AI จะเปิดได้แค่ฉบับที่ซ่อนแล้วผ่าน firmalways read ถ้าคุณต้องการให้เห็นข้อมูลจริง รัน firmalways allow-file ไฟล์ เอง

ใส่ค่าจริงกลับลงไฟล์

เมื่อ AI เขียนไฟล์ในเครื่องคุณ FirmAlways ใส่ชื่อและเบอร์จริงกลับให้ ตัว AI ยังเห็นแค่ placeholder และจะไม่ข้ามขั้นที่ต้องให้คุณอนุมัติ

ไม่ส่งสิ่งที่ไม่ควรส่ง

รหัสผ่าน API key และข้อมูลอ่อนไหวตามมาตรา 26 ที่อยู่คู่กับตัวบุคคล ถูกตัดออกเป็น «REMOVED_…» เสมอ

ส่งต้นฉบับได้เมื่อจำเป็น

รัน firmalways allow-next แล้วส่งข้อความเดิมอีกครั้ง ใช้ได้ครั้งเดียว ยกเว้นรหัสลับ

ติดตั้งด้วยคำสั่งเดียว

ใช้ได้บน macOS, Linux และ Windows (WSL) ต้องมี Node.js 18 ขึ้นไป สคริปต์ดาวน์โหลดจาก GitHub ตรวจ SHA-256 แล้วเพิ่ม hook ให้ Codex, ChatGPT Desktop และ Claude Code ที่พบในเครื่อง

curl -fsSL https://firmalways.meapplication.co.th/personal/install.sh | sh
  1. รันคำสั่งด้านบนใน Terminal (อ่านสคริปต์ก่อนได้ที่ install.sh)
  2. เปิด ChatGPT Desktop หรือ Codex ไปที่ Settings → Hooks แล้วกด Trust ให้ firmalways hook codex (Codex ให้ตรวจ hook ใหม่ก่อนใช้งานทุกครั้ง)
  3. ลองดูผลโดยไม่ส่งจริง: firmalways check "โทร 081-234-5678"

คำสั่งที่ใช้บ่อย: firmalways status, firmalways report, firmalways clip (ทำคลิปบอร์ดให้ปลอดภัยก่อนวางในเว็บ AI), firmalways off และ firmalways uninstall

ใช้ AI บนเว็บเป็นหลัก? มีส่วนขยายเบราว์เซอร์สำหรับ Chrome, Edge และ Brave ด้วย โค้ดทั้งหมดอยู่บน GitHub ภายใต้ Apache-2.0

ข้อความของคุณไม่ไปไหน

  • ตรวจในเครื่องของคุณ FirmAlways ไม่ส่งข้อความหรือข้อมูลการใช้งานไปที่ FirmAlways หรือที่อื่น
  • ค่าจริงที่ซ่อนไว้เก็บในเครื่อง (~/.firmalways สิทธิ์เฉพาะคุณ) และลบอัตโนมัติหลัง 24 ชั่วโมง หรือเมื่อรัน firmalways forget
  • รายงานเก็บเฉพาะจำนวนและประเภทข้อมูล ไม่เก็บข้อความ
  • ฟรีตลอด ไม่จำกัดจำนวนข้อความ และไม่ลดความแม่นยำเพื่อให้อัปเกรด

ข้อจำกัดที่ควรรู้

  • Hook แก้ข้อความที่คุณส่งไม่ได้ ทำได้แค่หยุดไว้ คุณจึงต้องกดวางฉบับที่ซ่อนแล้วส่งอีกครั้ง
  • แอป ChatGPT อาจตั้งชื่อแชตใหม่จากข้อความแรก ซึ่ง hook ควบคุมไม่ได้ ถ้าข้อความแรกมีข้อมูลส่วนตัว ให้รัน firmalways clip ก่อนวาง
  • คำตอบในแอปยังแสดงเป็น placeholder คัดลอกคำตอบแล้วรัน firmalways clip --restore เพื่อใส่ค่าจริงกลับ
  • ตัวกันไฟล์ดูจากชื่อไฟล์ในคำสั่งของ AI ถ้าคำสั่งเข้าถึงไฟล์โดยไม่ระบุชื่อ (เช่น ผ่านสคริปต์) อาจหลุดได้ จึงเป็นด่านกัน ไม่ใช่ sandbox การแยกระบบจริงอยู่ใน FirmAlways Gate
  • OCR อาจอ่านตารางที่แน่นบางส่วนไม่ออก ส่วนที่อ่านไม่ออกจะไม่ถูกส่งให้ AI
  • ชื่อที่ไม่มีคำนำหน้า และข้อมูลที่ระบุตัวตนได้จากบริบทเท่านั้น อาจตรวจไม่พบ ข้อมูลที่แทนด้วย placeholder ยังเป็นข้อมูลส่วนบุคคลตาม PDPA

ถ้าต้องการปกป้องระบบและไฟล์ที่ AI agent เข้าถึง ดู FirmAlways Gate และถ้าองค์กรต้องการบังคับนโยบายให้ทุกคน ดู FirmAlways Pro
