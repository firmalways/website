FirmAlways Personal
ความสามารถ ติดตั้ง ความเป็นส่วนตัว Gate Pro EN

ฟรีตลอด ไม่จำกัดจำนวนข้อความ ทำงานในเครื่องของคุณ

FirmAlways Personal ใช้ AI ได้เหมือนเดิม โดยข้อมูลส่วนตัวไม่หลุดออกไป

ส่วนขยายเบราว์เซอร์ที่ตรวจข้อความก่อนส่งให้ ChatGPT, Claude, Gemini, Copilot, Perplexity และ DeepSeek ข้อมูลส่วนบุคคลถูกแทนด้วย «PHONE_1» รหัสผ่านไม่ถูกส่ง และคำตอบแสดงค่าจริงบนจอคุณ ใช้บัญชีเดิม ไม่ต้องมี API key ไม่ต้องใช้ Terminal

ดาวน์โหลดฟรี วิธีติดตั้ง 1 นาที

สิ่งที่ FirmAlways Personal ทำให้คุณ

ปกป้องทุกครั้งที่ใช้ AI

ตรวจตอนวางและก่อนกดส่ง

ข้อความที่วางถูกตรวจก่อนเข้าไปในช่องพิมพ์ ข้อความที่พิมพ์เองถูกตรวจเมื่อกด Enter หรือปุ่มส่ง

ซ่อนแล้วคืนค่า

เลขบัตรประชาชน (ตรวจ checksum) เบอร์โทร อีเมล บัญชี บัตร ชื่อที่มีคำนำหน้า ที่อยู่ วันเกิด ถูกแทนด้วย placeholder แล้วแสดงค่าจริงในคำตอบให้คุณคนเดียว

ไม่ส่งสิ่งที่ไม่ควรส่ง

รหัสผ่าน API key และข้อมูลอ่อนไหวตามมาตรา 26 ที่อยู่คู่กับตัวบุคคล ถูกหยุดไว้ก่อนออกจากเครื่อง

Privacy Mirror

ดูข้อความของคุณเทียบกับสิ่งที่ AI ได้รับจริง จะให้ถามก่อนส่งทุกครั้งก็ได้

ปรับได้เต็มที่ ฟรีทั้งหมด

Basic และ Advanced Mode

สวิตช์ 4 ตัวสำหรับคนทั่วไป หรือเลือกการทำงานรายประเภท: ส่งปกติ แจ้งเตือน ถามก่อน ซ่อน ลบทิ้ง บล็อก

คำลับและกฎของคุณ

เพิ่มชื่อโปรเจกต์ ชื่อลูกค้า หรือรูปแบบรหัสพนักงานที่ต้องการปกป้อง

Policy Library

Thailand PDPA Baseline, Global Privacy Baseline, Personal Finance Protection (OTP, CVV, PIN) และ Developer Secret Protection พร้อมแหล่งอ้างอิงกฎหมายและ ISO

รายงานความเป็นส่วนตัว

ดูว่า 7 หรือ 30 วันที่ผ่านมา คุณเกือบส่งข้อมูลอะไรให้ AI บ้าง เก็บแค่จำนวนและประเภท ไม่เก็บข้อความ

มีหน้าสแกนเอกสารสำหรับข้อความและไฟล์ .txt .md .csv .json .docx และเอกสารหนึ่งหน้าสำหรับแนะนำ FirmAlways ให้หัวหน้าหรือ DPO โดยไม่แนบข้อมูลการใช้งานของคุณ

ติดตั้งใน 1 นาที

ใช้ได้กับ Chrome, Edge, Brave, Arc และเบราว์เซอร์ที่ใช้ Chromium ระหว่างรอขึ้น Chrome Web Store ให้ติดตั้งจากไฟล์ดังนี้

  1. ดาวน์โหลด firmalways-personal-v0.1.0.zip แล้วแตกไฟล์
  2. เปิด chrome://extensions (Edge ใช้ edge://extensions) แล้วเปิด Developer mode
  3. กด Load unpacked แล้วเลือกโฟลเดอร์ที่แตกไว้ จากนั้นเปิด ChatGPT, Claude หรือ Gemini ใช้งานได้ทันที

โค้ดทั้งหมดเปิดให้ตรวจสอบบน GitHub ภายใต้ Apache-2.0

ข้อความของคุณไม่ไปไหน

  • ตรวจในเบราว์เซอร์ของคุณ ส่วนขยายไม่ส่งข้อความหรือข้อมูลการใช้งานไปที่ FirmAlways หรือที่อื่น
  • ค่าจริงที่ซ่อนไว้อยู่ในหน่วยความจำ หายไปเมื่อปิดเบราว์เซอร์ หรือเมื่อกด "ล้างค่าจริง"
  • รายงานเก็บเฉพาะจำนวน ประเภทข้อมูล และชื่อเว็บ ไม่เก็บข้อความ
  • ฟรีตลอด ไม่จำกัดจำนวนข้อความ และไม่ลดความแม่นยำเพื่อให้อัปเกรด

ข้อจำกัดที่ควรรู้

  • ข้อความที่พิมพ์เองจะอยู่ในช่องพิมพ์ของเว็บก่อนกดส่ง เว็บนั้นอ่านได้ทางเทคนิค การวางข้อความปลอดภัยกว่าเพราะถูกตรวจก่อน
  • ยังไม่ตรวจไฟล์และรูปที่อัปโหลด เสียง และแอปมือถือ ให้ใช้หน้าสแกนเอกสารทำฉบับที่ปลอดภัยก่อน
  • ชื่อที่ไม่มีคำนำหน้า และข้อมูลที่ระบุตัวตนได้จากบริบทเท่านั้น อาจตรวจไม่พบ
  • ข้อมูลที่แทนด้วย placeholder ยังเป็นข้อมูลส่วนบุคคลตาม PDPA เครื่องมือนี้ช่วยลดความเสี่ยง ไม่ได้ทำให้ผ่านกฎหมายโดยอัตโนมัติ
