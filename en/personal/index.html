FirmAlways Personal: use AI as you always do, without your personal data leaving

A hook you install once, like RTK, that checks every prompt before it goes to the AI in ChatGPT Desktop, Codex and Claude Code. If it finds a name, phone number, Thai ID or password, the prompt is not sent, and a safe copy is waiting on your clipboard to paste and send.

How it works

Before a prompt leaves your machine

You type

Draft a letter to นายสมชาย ใจดี, phone 081-234-5678

FirmAlways holds it

The prompt is not sent. The app shows that a hook stopped it and which kinds of data it found.

You paste (⌘V) and send

Draft a letter to นาย«PERSON_1», phone «PHONE_1». The AI only sees placeholders.

When the AI works on your machine

Files with personal data stay closed

Before the AI opens a PDF, Word, Excel, CSV or image, FirmAlways reads it on your machine, including scanned pages with Thai OCR. If it holds personal data, the AI only gets a masked copy through firmalways read. To show it the real data, run firmalways allow-file file yourself.

Real values go back into files

When the AI writes a file on your machine, FirmAlways puts the real name and number back. The AI still only sees placeholders, and no approval step is ever skipped.

Never sends what it should not

Passwords, API keys and PDPA section 26 sensitive data about a person are always cut out as «REMOVED_…».

Send the original when you must

Run firmalways allow-next and send the prompt again. It works once, and never for secrets.

Install with one command

macOS, Linux and Windows (WSL), with Node.js 18 or newer. The script downloads from GitHub, checks the SHA-256 and adds the hook to the Codex, ChatGPT Desktop and Claude Code it finds.

curl -fsSL https://firmalways.meapplication.co.th/personal/install.sh | sh
  1. Run the command above in a terminal (read the script first: install.sh).
  2. Open ChatGPT Desktop or Codex, go to Settings → Hooks and click Trust on firmalways hook codex. Codex reviews every new hook before it runs.
  3. Try it without sending anything: firmalways check "call 081-234-5678"

Everyday commands: firmalways status, firmalways report, firmalways clip (make your clipboard safe before pasting into an AI website), firmalways off and firmalways uninstall.

Mostly use AI in the browser? There is also a browser extension for Chrome, Edge and Brave. All code is on GitHub under Apache-2.0.

Your text goes nowhere

  • Checked on your machine. FirmAlways sends no text or usage data to FirmAlways or anyone else.
  • Masked real values stay on your machine (~/.firmalways, readable only by you) and are deleted after 24 hours, or when you run firmalways forget.
  • The report keeps counts and data types only, never text.
  • Free for good, no message limits, and detection is never weakened to make you upgrade.

Limits you should know

  • A hook cannot rewrite what you send, only stop it, so you paste the safe copy and send again.
  • The ChatGPT app may name a new chat from its first message, which hooks cannot control. If that first message has personal data, run firmalways clip before pasting.
  • Answers in the app still show placeholders. Copy the answer and run firmalways clip --restore to put real values back.
  • The file guard looks for file names in the AI's commands. A command that reaches a file without naming it (through a script, say) can get past it: it is a guard, not a sandbox. Enforced isolation is FirmAlways Gate.
  • OCR can miss parts of dense tables. What it cannot read is left out, never sent unmasked.
  • Names without a title, and data that identifies someone only from context, may be missed. Placeholder data is still personal data under the PDPA.
